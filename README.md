# ACM FAST TechOps Department — Official Portfolio Website

Official portfolio website for the **ACM FAST Technical Operations (TechOps) Department**, highlighting its responsibilities, technical projects, governance, and the dedicated contributions of **Coders Club** to the ACM FAST society.

## Technologies Used
- **HTML5 & CSS3:** Semantic, responsive single-page academic layout inspired by classic institutional editorial design.
- **Google Fonts:** *Libre Baskerville* (serif headings) and *Inter* (body typography).
- **Hosting & CI/CD:** GitHub + Vercel automatic static deployment.

## Setup & Deployment Instructions
1. Clone or fork this repository.
2. Open `index.html` directly in any web browser to preview locally (no build step or dependencies required).
3. Push changes to the `main` branch; Vercel automatically deploys updates to the live public URL.
