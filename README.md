# ACM FAST TechOps Department — Official Portfolio Website

Official portfolio website for the **ACM NUCES Karachi Technical Operations (TechOps) Department** (Tenure 2026–27), showcasing departmental web deliverables, governance, and the dedicated contributions of **Coders Club** to the ACM FAST society.

## Technologies Used
- **HTML5 & CSS3 (`index.html`, `styles.css`):** Cleanly separated semantic markup and modular responsive stylesheet.
- **Vanilla JavaScript:** Instant client-side view switching with browser history support and zero page-scroll jumps.
- **Google Fonts:** *Libre Baskerville* (editorial serif headings) and *Inter* (body typography).
- **Hosting & CI/CD:** GitHub + Vercel static deployment.

## Setup & Deployment Instructions
1. Clone or fork this repository.
2. Open `index.html` in any web browser to run locally (no build step or dependencies required).
3. Push changes to the `main` branch; Vercel automatically deploys updates to the live public URL.
